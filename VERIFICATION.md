## Известные ограничения (не баги)

| Пункт | Описание |
|---|---|
| ID монетизации = 0 | Заглушки до публикации опыта — обязательно заменить перед продом |
| `rbxassetid://0` эмбиент/музыка | Заполнить реальными ассетами; код деградирует без вылета |
| Bootstrap-карта | Временный блокаут; заменяется реальной моделью (этап художников) |
| Streaming | Включить руками в Studio (свойство read-only для скриптов) |
| «Гардероб» эпохи (ролеплей-костюмы) | Пока только база: пресеты тонов в AvatarPresets; роутер костюмов эпох — отдельный этап |
| Эксклюзивные позы VIP | В v2.0 позы общие (серверные C0, без ассетов); VIP-ассетные наборы — позже |
