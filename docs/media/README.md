# Медиа-активы (промо)

Промо-материалы для страницы опыта в Roblox Creator Hub. Исходники (кадры,
голосовые дорожки, скрипты сборки) смотри в воркспейсе агента — здесь только
готовые файлы, чтобы не раздувать историю git.

| Файл | Формат | Что это | Куда использовать |
|---|---|---|---|
| `SPB-Landmarks-Demo.mp4` | 1920×1080 · 74 с · H.264+AAC | Основной демо-трейлер с нарративом: город → дворец → Исаакий → Спас → разводной мост/Тень → гардероб | Thumbnail-видео опыта, посты, дискорд |
| `SPB-Landmarks-Shorts.mp4` | 1080×1920 · 35 с · H.264+AAC | Вертикальный ролик-тизер: «Это Петербург (из примитивов)» | YouTube Shorts, Reels, TikTok |
| `city-plan-v5.png` | PNG схема | Актуальный план игровой карты (v5) — зоны, интерьеры, моста, каналы | для обложки о формате экспы + доки |

## Правило версиирования медиа

- Новый ролик = новый файл `*-vN.mp4`, старые не перезаписываем (история уже хранит diff)
- Ограничение: файлы > 25 МБ добавлять только через Git LFS (пока оба в пределах)
